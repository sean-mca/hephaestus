    - Use ort::inputs! macro with TensorRef::from_array_view for session.run() inputs

    postprocess.rs: Create module with two pub(crate) functions. fn softmax(logits: &[f32]) -> Vec of f32: numerically stable softmax (subtract max, exp, normalize). fn argmax_with_score(probs: &[f32]) -> (usize, f32): return index and value of the maximum element. Both are pure functions, no external dependencies.

    error.rs: Expand CoreError if needed. Ensure variants cover: ort Session creation errors (wrap ort::Error), tokenizer load errors, tokenizer encode errors, ndarray shape errors, serde_json parse errors for config.json, missing id2label in config.json. Use #[from] for std::io::Error. Use String wrapping for ort and tokenizer errors (they may not implement std::error::Error consistently). Add a JsonParse variant wrapping serde_json::Error via #[from].

    pipeline.rs -- ClassifierPipeline::new(model_dir: &Path):
    1. Build model_path = model_dir.join("model.onnx"), tokenizer_path = model_dir.join("tokenizer.json"), config_path = model_dir.join("config.json")
    2. Load ONNX session: Session::builder()?.with_optimization_level(GraphOptimizationLevel::Level3)?.commit_from_file(&model_path)?
    3. Load tokenizer: Tokenizer::from_file(&tokenizer_path).map_err(|e| CoreError::Tokenization(e.to_string()))?
    4. Configure tokenizer truncation: call tokenizer.with_truncation(Some(tokenizers::TruncationParams { max_length: 512, ..Default::default() })) to mitigate T-01-02 DoS threat
    5. Validate tokenizer-model compatibility (TOKN-03): read session.inputs() to get model input names. Assert both "input_ids" and "attention_mask" are present. If missing, return CoreError::ModelValidation with descriptive message listing expected vs actual input names.
    6. Load config.json, parse as serde_json::Value, extract id2label mapping. The id2label field is a JSON object with string keys ("0", "1", ...) mapping to label strings ("NEGATIVE", "POSITIVE"). Parse into Vec of String ordered by numeric key. If id2label is missing from config.json, return CoreError::ModelValidation.
    7. Return Self { session, tokenizer, id2label }

    pipeline.rs -- Pipeline::prepare(&self, input: String):
    1. Encode text: self.tokenizer.encode(input.as_str(), true).map_err(|e| CoreError::Tokenization(e.to_string()))?
    2. Extract input_ids: encoding.get_ids().iter().map(|&id| id as i64).collect() (u32 -> i64 cast per Pitfall 4)
    3. Extract attention_mask: encoding.get_attention_mask().iter().map(|&m| m as i64).collect()
    4. Return PreparedInput { input_ids, attention_mask, sequence_length: encoding.len() }

    pipeline.rs -- Pipeline::execute(&mut self, prepared: PreparedInput):
    1. Create ndarray::Array2 for input_ids: shape (1, seq_len) from prepared.input_ids
    2. Create ndarray::Array2 for attention_mask: shape (1, seq_len) from prepared.attention_mask
    3. Run inference: self.session.run(ort::inputs!["input_ids" => TensorRef::from_array_view(&input_ids_array.view())?, "attention_mask" => TensorRef::from_array_view(&attention_mask_array.view())?]?)?
    4. Extract logits: outputs[0].try_extract_tensor::<f32>()? then .as_slice().unwrap()
    5. Apply softmax: postprocess::softmax(logits_slice)
    6. Get top prediction: postprocess::argmax_with_score(&probs)
    7. Map index to label: self.id2label[idx].clone()
    8. Return ClassifierOutput { label, score }

    lib.rs: Add pub mod postprocess; declaration. Ensure pipeline and error modules are declared and key types re-exported.

    Per rule err-no-unwrap-prod: avoid unwrap() in production paths. Use ? operator with proper error conversions. The only acceptable unwrap() is on logits.as_slice() which is guaranteed to succeed for contiguous arrays -- use expect() with explanation per rule err-expect-bugs-only.
