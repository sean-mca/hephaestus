<objective>
Replace String cloning with Arc of str in StageTimer for zero-allocation metrics recording on every request.

Purpose: StageTimer clones model_id as a String three times per request (once per metrics macro call in time() and finish_request()). Each clone heap-allocates and copies the string. Changing to Arc of str makes each clone an atomic ref-count increment (single CPU instruction) instead of a heap allocation. Additionally, the metrics crate SharedString type has a From impl for Arc, so the label value avoids further copying into the metrics registry.

Output: Updated metrics.rs with Arc str field, updated handlers.rs and grpc/inference.rs callers to pass &str directly.
</objective>
