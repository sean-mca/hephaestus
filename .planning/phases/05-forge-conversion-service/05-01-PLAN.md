<objective>
Build the complete Forge conversion service as a standalone Python FastAPI application that converts HuggingFace models to ONNX format, validates conversions, uploads to S3, and returns results. Covers FORG-01, FORG-02, FORG-03, FORG-04, and decisions D-01 through D-14.

Purpose: Completes the conversion backend that Hephaestus calls when no ONNX export exists in S3 or HuggingFace.
Output: A runnable, tested, containerized Forge service in the forge/ directory.
</objective>

## Phase Goal

**As a** Hephaestus operator, **I want to** have models without ONNX exports automatically converted and cached by a persistent Forge service, **so that** I can deploy any HuggingFace model and the full resolution chain handles conversion transparently.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hephaestus -> Forge | HTTP POST with model_id string crosses service boundary |
| Forge -> HuggingFace | Downloads external PyTorch model weights and tokenizer |
| Forge -> S3 | Uploads converted ONNX artifacts to shared cache bucket |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | models.py ConvertRequest | medium | mitigate | Pydantic field_validator on model_id rejects empty strings, ".." traversal, and special characters — mirrors Rust validate_model_id |
| T-05-02 | Tampering | storage.py S3 key construction | medium | mitigate | model_id validated before reaching storage; S3 key built from validated components only, no user-controlled path segments beyond org/model |
| T-05-03 | DoS | converter.py large model conversion | medium | mitigate | Sequential queue (D-10) limits to one conversion; asyncio.wait_for with CONVERSION_TIMEOUT_SECS prevents unbounded runtime; k8s pod memory limits (external) |
| T-05-04 | DoS | queue.py unbounded result cache | low | accept | Single replica restarts clear cache (D-09). Conversion is infrequent (new model deployments only). Bounded cache deferred to horizontal scaling phase. |
| T-05-05 | Tampering | pyproject.toml dependency chain | low | accept | All dependencies from public PyPI, pinned via uv.lock. Package Legitimacy Audit completed in RESEARCH.md — all packages verified as legitimate (HuggingFace, AWS, Microsoft, FastAPI orgs). |
| T-05-SC | Tampering | pip/uv installs | high | mitigate | uv.lock for reproducible installs + Package Legitimacy Audit table in RESEARCH.md. All SUS verdicts reviewed and approved with rationale (tooling limitation, not actual suspicion). |
</threat_model>
