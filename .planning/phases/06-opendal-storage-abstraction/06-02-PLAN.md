| T-06-06 | Tampering | STORAGE_ROOT path traversal | low | accept | STORAGE_ROOT is set via k8s manifest by operators, not user input. Internal service with controlled deployments. Path is passed to OpenDAL which manages filesystem access within the configured root. |
