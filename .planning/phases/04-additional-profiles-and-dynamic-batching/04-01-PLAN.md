<objective>
First multi-profile vertical slice: add embeddings profile support and generalize the runtime from classifier-only to multi-profile dispatch. After this plan, a user can deploy an embeddings model (e.g., sentence-transformers/all-MiniLM-L6-v2) and receive L2-normalized float vectors from POST /infer, while existing classifier deployments continue working unchanged.

Implements D-01 (auto-detect profile from config.json), D-02 (optional MODEL_PROFILE override), D-03 (PipelineKind enum dispatch), D-04 (single /infer endpoint for all profiles), D-05 (model-determined output shapes via serde_json::Value), and PROF-02 (embeddings profile).

Purpose: Transform the single-profile classifier runtime into a multi-profile inference engine.
Output: Working embeddings profile, generalized handler/state/config, profile detection module.
</objective>

Implement detect_profile() that takes a serde_json::Value reference and an Option of str for override_profile. Per D-02, check override first via a parse_profile_string helper. Per D-01, check the config.json "architectures" array: names ending with "ForSequenceClassification" map to Classifier, "ForTokenClassification" to TokenClassifier, "ForConditionalGeneration" to Seq2Seq, "Model" or "ForMaskedLM" to Embeddings. Return CoreError::Config on detection failure. Add unit tests: test_detect_classifier_from_architectures, test_detect_embeddings_from_architectures, test_detect_seq2seq_from_architectures, test_detect_token_classifier_from_architectures, test_override_takes_precedence, test_fallback_to_pipeline_tag, test_unknown_architecture_returns_error.

    **pipeline.rs (modify):**
    Add EmbeddingsPipeline struct with fields session: Session, tokenizer: Tokenizer. Implement EmbeddingsPipeline::new(model_dir: &Path) -> Result constructor following ClassifierPipeline::new() pattern (steps 1-5 are identical: resolve ONNX file, load session with Level3 optimization, load tokenizer, configure 512-token truncation, validate input_ids + attention_mask). No id2label loading needed. Implement Pipeline for EmbeddingsPipeline with Input=String, Prepared=PreparedInput, Output=Vec of f32. The prepare() method is identical to ClassifierPipeline::prepare() -- extract a shared tokenize_text helper function that both use. The execute() method runs ONNX inference identically to ClassifierPipeline (ndarray tensor construction, session.run), then extracts the output tensor as f32, determines hidden_dim from output shape (output is shape [1, seq_len, hidden_dim]), calls postprocess::mean_pool with the token embeddings slice and the prepared attention_mask, then calls postprocess::l2_normalize on the result, returning the Vec of f32.

    Add PipelineKind enum per D-03 with variants Classifier(ClassifierPipeline) and Embeddings(EmbeddingsPipeline). Implement PipelineKind::prepare(&self, input: String) -> Result of PreparedInput, CoreError that matches on variant and delegates to inner pipeline's prepare(). Implement PipelineKind::execute(&mut self, prepared: PreparedInput) -> Result of serde_json::Value, CoreError that matches on variant: Classifier calls inner execute() and serializes as {"label": label, "score": score}; Embeddings calls inner execute() and serializes as {"embedding": vec}.

    Add unit test for PipelineKind variant size check using std::mem::size_of to verify no Clippy large_enum_variant issues.

    **postprocess.rs (modify):**
    Add mean_pool function: takes token_embeddings slice of f32, attention_mask slice of i64, and hidden_dim usize. Computes masked mean pooling: for each token, multiply embedding by attention_mask value, sum across tokens, divide by mask_sum clamped to minimum 1e-9. Returns Vec of f32 with length hidden_dim. Add l2_normalize function: takes mutable slice of f32, computes L2 norm (sqrt of sum of squares), clamps to minimum 1e-12, divides each element by norm in-place. Both functions are pub(crate). Add unit tests: test_mean_pool_excludes_padding (verify padding tokens with mask=0 do not affect result), test_mean_pool_single_token, test_l2_normalize_unit_vector (verify output has L2 norm approximately 1.0), test_l2_normalize_zero_vector (verify no division by zero).

    **error.rs (modify):**
    No new variants needed -- existing CoreError::Config covers profile detection failures, CoreError::Inference covers ONNX errors.

    **lib.rs (modify):**
    Add pub mod profile declaration. Update re-exports to include: ModelProfile, detect_profile from profile module; PipelineKind, EmbeddingsPipeline from pipeline module. Keep postprocess as pub(crate).
