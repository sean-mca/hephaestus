    **Step 2 -- Create StageTimer abstraction (crates/hephaestus-api/src/metrics.rs)**

    Per D-09, create a deep-module timer that hides all metrics crate interaction. Callers never touch metrics macros directly.

    - pub fn install_recorder() -> Result of metrics_exporter_prometheus::PrometheusHandle, anyhow::Error:
      - Call metrics_exporter_prometheus::PrometheusBuilder::new().install_recorder()
      - Return the PrometheusHandle for rendering on /metrics
      - This MUST be called once at startup before any metrics are recorded

    - pub struct StageTimer with a single field model_id: String
    - impl StageTimer:
      - pub fn new(model_id: String) -> Self
      - pub fn time of generic T, taking stage as &'static str and f as impl FnOnce() -> T, returning T:
        - Record start with Instant::now()
        - Call f() to get the result
        - Record elapsed as f64 seconds
        - Call metrics::histogram!("hephaestus_stage_duration_seconds", "stage" => stage, "model_id" => self.model_id.clone()).record(elapsed)
        - Return the result
        - Per D-08, stage values will be "tokenization", "inference", "postprocessing"
      - pub fn finish_request(&self, start: std::time::Instant, success: bool):
        - Record elapsed as f64 seconds from start
        - Call metrics::histogram!("hephaestus_request_duration_seconds", "model_id" => self.model_id.clone()).record(elapsed)
        - Call metrics::counter!("hephaestus_requests_total", "model_id" => self.model_id.clone(), "status" => if success then "ok" else "error").increment(1)
        - Per D-10, all metrics carry model_id label

    - pub async fn metrics_handler(State(state): State of Arc of AppState) -> String:
      - Call state.metrics_handle.render() to produce Prometheus exposition text
      - Return the rendered string

    Add unit tests in a #[cfg(test)] mod tests block:
    - Test that StageTimer::time returns the closure result unchanged
    - Test that StageTimer::new accepts a model_id string

    **Step 3 -- Add metrics_handle to AppState (crates/hephaestus-api/src/state.rs)**

    **Step 4 -- Wire StageTimer into infer handler (crates/hephaestus-api/src/handlers.rs)**

    Modify the infer handler to use StageTimer per D-09:
    - Create a StageTimer at the start of the handler: let timer = StageTimer::new(state.model_id.clone())
    - Record overall request start time: let request_start = Instant::now()
    - Wrap the pipeline.prepare() call: let prepared = timer.time("tokenization", || pipeline.prepare(req.text))?
    - Wrap the pipeline.execute() call: let output = timer.time("inference", || pipeline.execute(prepared))?
    - After building the response, call timer.finish_request(request_start, true)
    - On error paths, call timer.finish_request(request_start, false) before returning the error

    **Step 2 -- Create telemetry init (crates/hephaestus-api/src/telemetry.rs)**

    Per D-11 and RESEARCH Pattern 2 (Conditional OTel Layer), create a telemetry initialization function. The function takes individual parameters (not the Config struct) to keep the API crate independent of the binary crate.

    - pub fn init(log_level: &str, otel_endpoint: Option of &str) -> Result of (), anyhow::Error:
      - Build a JSON fmt layer: tracing_subscriber::fmt::layer().json().with_target(true)
      - Build an EnvFilter: try from RUST_LOG first (try_from_default_env), fall back to the log_level parameter. This preserves the Phase 1 dual LOG_LEVEL/RUST_LOG pattern
      - Conditionally build the OTel layer per D-11: if otel_endpoint is Some:
        - Build an OTLP SpanExporter via opentelemetry_otlp::SpanExporter::builder().with_tonic().build()
        - Build an SdkTracerProvider with the batch exporter: opentelemetry_sdk::trace::SdkTracerProvider::builder().with_batch_exporter(exporter).build()
        - Set global tracer provider: opentelemetry::global::set_tracer_provider(provider.clone())
        - Create a tracer: provider.tracer("hephaestus")
        - Build the layer: tracing_opentelemetry::OpenTelemetryLayer::new(tracer)
        - Wrap in Some()
      - If otel_endpoint is None, the otel_layer is None
      - Assemble the subscriber using Registry pattern: tracing_subscriber::Registry::default().with(env_filter).with(fmt_layer).with(otel_layer)
      - Call .init() on the assembled subscriber
      - Log at info level whether OTel export is active or disabled
      - Per RESEARCH Pitfall 1, this function MUST be called inside the tokio runtime (after #[tokio::main])

    - pub fn shutdown():
      - Call opentelemetry::global::shutdown_tracer_provider()
      - Flushes any pending OTel spans before process exit

    Add a #[cfg(test)] test that verifies init() with None endpoint does not panic (basic smoke test -- OTel exporter requires a real collector so only the None path is unit-testable).
