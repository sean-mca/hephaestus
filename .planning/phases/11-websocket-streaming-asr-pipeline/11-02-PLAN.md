<task type="auto">
  <name>Task 1: WebSocket handler module with audio buffer, PCM conversion, and param validation</name>
  <files>crates/hephaestus-api/src/ws.rs</files>
  <action>
Create a new ws.rs module in crates/hephaestus-api/src/. This module handles the WebSocket transport layer for streaming audio transcription. It does NOT call the inference pipeline — that integration happens in Plan 11-03.

Define a TranscribeParams struct deriving Debug and Deserialize (serde) with three fields: sample_rate (u32), channel (String), and encoding (String). This struct is extracted from query parameters at connection time per D-05.

Define an AudioEncoding enum with F32 and I16 variants. Add a from_str function or FromStr impl that maps "f32" to F32 and "i16" to I16, returning an error for anything else (D-06). This is used internally after parsing TranscribeParams.

Define a TranscriptMessage struct deriving Debug, Clone, and Serialize (serde) with three fields: channel (String), chunk_index (u64), and text (String). This is the JSON shape sent back to clients per D-07.

Define two PCM conversion functions. First: i16_bytes_to_f32 accepting a byte slice, interpreting every 2 bytes as a little-endian i16, converting each sample to f32 by dividing by 32768.0 to normalize to [-1.0, 1.0]. Return Vec of f32. Second: f32_bytes_to_samples accepting a byte slice, interpreting every 4 bytes as a little-endian f32, collecting into Vec of f32. Both functions should use chunks_exact to handle any trailing bytes (ignore incomplete samples at the end — do not panic).

Define an AudioBuffer struct with four fields: samples (Vec of f32), window_samples (usize), overlap_samples (usize), and chunk_index (u64). Add a constructor new(window_secs: f32, overlap_secs: f32, sample_rate: u32) that computes window_samples and overlap_samples by multiplying seconds by sample_rate and casting to usize. Add a push method taking a slice of f32, extending the internal samples buffer, then extracting complete windows. The extraction loop: while samples.len() is at least window_samples, clone the first window_samples elements into a window vec, increment chunk_index, drain the first (window_samples - overlap_samples) elements from the buffer (keeping overlap for next window), and push (window, chunk_index_before_increment) to a results vec. Return the results vec (possibly empty). Add a flush method that returns the remaining samples (if any) as a final short window with the current chunk_index, incrementing chunk_index. Returns Option of (Vec of f32, u64).

Also enforce a maximum buffer size to prevent memory exhaustion per the research anti-patterns. Cap the internal samples vec at 2 times window_samples. If samples.len exceeds this cap after extending, truncate from the front (drain the oldest samples) and log a warning via tracing::warn. This prevents a slow consumer or fast sender from exhausting memory (T-11-05 DoS mitigation).

Define the ws_transcribe async handler function. It takes WebSocketUpgrade, Query of TranscribeParams, and State of Arc of AppState as axum extractors, returning Result of impl IntoResponse, ApiError. Validate: if params.sample_rate is not 16000, return ApiError::BadRequest with a message stating only 16kHz is supported (D-08). Parse params.encoding via the AudioEncoding from_str — if it fails, return ApiError::BadRequest listing f32 and i16 as valid encodings (D-06). If validation passes, call ws.on_upgrade with a closure that invokes handle_transcribe_socket passing the socket, params, and state.

Define handle_transcribe_socket as an async function taking WebSocket, TranscribeParams, and Arc of AppState. Use futures_util::StreamExt to split the socket into sender and receiver (or iterate the receiver directly). Create an AudioBuffer with default window of 30.0 seconds and overlap of 1.0 second (these defaults will be configurable via env vars in Plan 11-03). Parse the AudioEncoding from params.encoding. Loop over incoming messages from the receiver. On binary message: convert bytes to f32 samples using the appropriate PCM conversion function based on encoding. Call buffer.push with the samples. For each window returned by push, construct a TranscriptMessage with channel from params, chunk_index from the window tuple, and text set to an empty string (placeholder — Plan 11-03 wires the actual inference). Serialize the TranscriptMessage to JSON and send it as a text message via the sender. On close message or error: call buffer.flush, and if there are remaining samples, similarly construct and send a final TranscriptMessage. Break the loop. Add an idle timeout: if no message is received within 30 seconds, close the connection (D-06 DoS mitigation). Use tokio::time::timeout wrapping each recv call for this.

Include comprehensive unit tests in a cfg(test) module at the bottom of ws.rs. Test AudioBuffer::new computes correct window and overlap samples (30.0s at 16000Hz = 480000 window_samples, 1.0s = 16000 overlap_samples). Test AudioBuffer::push returns no windows when insufficient samples, returns exactly one window when samples reach window_samples, returns multiple windows if enough samples for two windows. Test that push drains correctly accounting for overlap. Test AudioBuffer::flush returns None on empty buffer and Some with remaining samples. Test i16_bytes_to_f32: known byte pair [0x00, 0x40] (which is i16 value 16384 in little-endian) converts to 0.5. Test f32_bytes_to_samples: known 4-byte f32 encoding roundtrips correctly. Test i16_bytes_to_f32 with empty input returns empty vec. Test that odd-length byte slices for i16 ignore the trailing byte.

| T-11-02 | Tampering | PCM byte conversion | medium | mitigate | Validate byte length is multiple of sample size (2 for i16, 4 for f32). chunks_exact ignores trailing bytes — no panic on malformed input. |
| T-11-03 | Information Disclosure | channel query param | low | mitigate | Channel label is used only as a display string in TranscriptMessage JSON. Never used in file paths, log interpolation, or system calls. |
| T-11-04 | Denial of Service | AudioBuffer memory | high | mitigate | Cap internal buffer at 2x window_samples. Excess samples drained from front with tracing::warn. Prevents unbounded memory growth from fast sender. |
| T-11-05 | Denial of Service | idle WebSocket connections | medium | mitigate | 30-second idle timeout on recv. Connections with no data within timeout are closed. Prevents connection slot exhaustion from idle clients. |
