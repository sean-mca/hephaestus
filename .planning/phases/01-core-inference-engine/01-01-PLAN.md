## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ENV -> Config | Environment variables are untrusted input parsed into typed Config struct |
| Filesystem -> Pipeline | ONNX model files loaded from disk into ort Session |
| User text -> Pipeline | Arbitrary text input flows through tokenization into ONNX inference |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | MODEL_PATH file loading | medium | mitigate | Validate MODEL_PATH is absolute path with no ".." components before passing to Session::builder().commit_from_file(). Reject relative or traversal paths with CoreError::ModelValidation. |
| T-01-02 | Denial of Service | Pipeline::prepare() tokenization | medium | mitigate | Configure tokenizer with truncation to model max sequence length (512 for distilbert). Prevents unbounded memory allocation from large input text. |
| T-01-03 | Denial of Service | Session::builder().commit_from_file() | low | accept | Model loading is one-time at startup. K8s pod resource limits (CPU/memory) constrain the process. Acceptable for internal service. |
| T-01-04 | Information Disclosure | CoreError Display messages | low | accept | Error messages may contain filesystem paths. Acceptable for internal service where logs are not externally exposed. Phase 2 HTTP layer will sanitize error responses. |
| T-01-SC | Tampering | cargo dependency installs | high | mitigate | All 13 packages passed legitimacy audit with OK verdict (see RESEARCH.md Package Legitimacy Audit). No [ASSUMED] or [SUS] packages. |
