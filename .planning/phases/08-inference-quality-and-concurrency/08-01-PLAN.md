<objective>
Fix the NER score normalization bug and remove dead code from the token classifier pipeline.

Purpose: Token classifier pipeline returns raw logit values (e.g., 8.89) instead of softmax probabilities in [0,1]. The classifier pipeline correctly applies softmax before argmax, but the token classifier path skips this step. This plan adds a softmax_argmax_per_token function that applies per-token softmax before argmax, replaces both single and batch token classifier call sites, and removes dead code from TokenClassifierPipeline::execute. Addresses SC-01 and SC-04.

Output: Corrected NER scores in [0,1] range, clean execute method.
</objective>
